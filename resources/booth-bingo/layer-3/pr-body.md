## Stack layer 3 of 3: celebration

Makes a BINGO feel like a win.

- `index.html`: adds a "BINGO!" banner with CSS-only confetti, and a "New card" reset button.
- `app.js`: shows the banner when `checkWin` finds a line; reset clears the card.
- `styles.css`: banner pop-in and falling confetti animations (no JavaScript animation, no libraries).

Builds on layer 2. Merging this PR merges the whole stack into `main`.

### Try it

Run `npm start`, open the URL it prints, get three in a row, then press **New card**.

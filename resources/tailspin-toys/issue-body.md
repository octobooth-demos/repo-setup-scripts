The games list is growing and it's getting hard to find what you're looking for. We need filtering on the main page by **publisher** and **category**.

## Requirements

- Add filter dropdowns (or similar UI) for publisher and category to the games listing page
- Populate filter options dynamically from the existing game data
- Support filtering by both fields simultaneously
- Persist filter selections in the URL query string so filtered views are shareable
- Ensure the filtered view updates without a full page reload
- Add any necessary API endpoints to support the filtering
- Include tests for the new functionality
